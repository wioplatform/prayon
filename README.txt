GitHub 교체 방법
1. 압축을 풉니다.
2. GitHub prayon 저장소에서 index.html과 assets 폴더의 파일들을 새 버전으로 교체합니다.
3. Commit changes를 누릅니다.
4. GitHub Pages가 다시 배포될 때까지 약 1~3분 기다립니다.
