PRAY ON v18 — 매주 말씀·상황별 기도문 관리자 관리

추가 기능
- 관리자 로그인 후 '이번 주 말씀·기도 관리' 영역 표시
- 주일 날짜, 예배 구분, 강단 제목, 성경 본문, 핵심문장 입력
- 이미지 아래 기본 기도문 입력
- 걱정·상처·분노·용기·감사·친구/학교 상황별 기도문 입력
- 임시저장 또는 공개 선택
- 최근 12개 주차 기록을 불러와 재수정 가능
- 사용자 페이지는 가장 최근에 공개된 주차 내용을 자동으로 표시
- DB 연결에 문제가 있으면 기존 기본 문구를 그대로 표시

설치
1. Supabase SQL Editor에서 supabase_v18_weekly_content.sql 전체 실행
2. GitHub 저장소에서 index.html, admin.html, config.js 교체
3. Commit changes 후 1~3분 기다리고 새로고침
4. 관리자 페이지 /prayon/admin.html 로그인
5. 이번 주 내용을 입력하고 '사용자 페이지에 공개' 체크 후 저장

안전성
- 기존 익명 기도함·기도했어요·신고·관리자 삭제 데이터는 변경하지 않습니다.
- 공개된 주차만 일반 이용자가 읽을 수 있고, 작성·수정은 관리자만 가능합니다.
